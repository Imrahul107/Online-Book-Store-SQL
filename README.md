# Online Book Store SQL Project

## 📚 Project Overview

This project is an SQL-based Online Book Store database project focused on storing, managing, and analyzing book, customer, and order-related data.

The project uses MySQL to create and work with a relational database and demonstrates practical SQL skills through data analysis queries.

## 🎯 Project Objectives

- Design and work with a relational database
- Import and manage book and order data
- Analyze sales and order information
- Retrieve meaningful business insights using SQL
- Practice filtering, sorting, grouping, and aggregation
- Use joins to combine data from multiple tables
- Apply subqueries, CTEs, and window functions
- Perform real-world SQL data analysis

## 📁 Dataset

The project uses CSV datasets related to an online bookstore.

### Dataset Files

- `Books.csv` — Contains book-related information

These datasets are used to perform SQL-based analysis and generate business insights.
